# Mapping Open Science Policy in China

Replication data and code for *Mapping Open Science Policy in China: A Structural, Temporal, and Spatial Analysis* (manuscript under review at *Humanities and Social Sciences Communications*).

This repository contains the full clean dataset of 21,242 open science policy entries (10,413 documents) issued by Chinese central, provincial, and prefectural authorities between 1998 and 2026, the panel of provincial science-and-technology innovation indicators (1998–2024), and all scripts that produce the figures and tables in the paper.

## For editors and referees

Everything underpinning the analysis is in this repository — no request to the authors is required. The fastest route to verifying a specific number in the paper:

| You want to check | Go to |
|---|---|
| Any figure or table in the paper | `code/figures/` — one script per figure, run from the repo root |
| The raw and cleaned policy corpus | `data/policy_entries_v5_3.xlsx` (21,242 entries), `data/policy_files_v5_3.xlsx` (10,413 documents) |
| What every column means | `data/data_dictionary.md` |
| The category coding scheme and the exact LLM prompt used | `docs/llm_classification_prompt.md` |
| Full method detail (Appendices A–G) | `docs/appendix.docx` |
| Any single number in the paper, traced to source | `outputs/audit/data_audit_master_v5.3.xlsx` (33 sheets) |
| The coupling statistics reported in Section 5 and Appendix G | `python code/compute_appendix_g.py` → regenerates `outputs/tables/appG_T1..T6_*.csv` |
| Pre-computed result tables and summary statistics | `outputs/tables/*.csv`, `outputs/stats/*.json` |

The `outputs/` directory ships pre-computed so that results can be inspected without running any code; every file in it is regenerated by the scripts in `code/`.

## Quick facts

- **Sample:** 10,413 policy documents, 21,242 clause-level entries
- **Time range:** 1998–2026 (2026 partial-year, excluded from stage statistics)
- **Geographic coverage:** Central government + 31 provincial-level regions + prefectural cities
- **Open science categories:** Open Access (OA), Open Data (OD), Open-Source Software (OSS), Open Educational Resources (OERs), Citizen Science (CS), Open Peer Review (OPR), Open Infrastructure (OI), Open Research Methods (ORM)
- **Source:** Pkulaw (北大法宝) policy database, retrieved 24 April 2026

## How to use

### Inspecting the data

The two primary datasets are Excel files; open them in Excel, LibreOffice, or load with Python:

```python
import pandas as pd
entries = pd.read_excel("data/policy_entries_v5_3.xlsx", sheet_name="政策条目")
files   = pd.read_excel("data/policy_files_v5_3.xlsx",   sheet_name="Sheet1")
panel   = pd.read_excel("data/tech_indicators_panel_1998_2024.xlsx", sheet_name="分省面板数据")
```

Field-by-field documentation is in `data/data_dictionary.md`.

`data/pre_correction/` holds the same two tables as they stood *before* the final manual-correction pass described in the appendix. They are deposited so that the correction step is auditable: diffing a pre-correction table against its analysis counterpart shows exactly which records were amended and how. All results in the paper are computed from the analysis versions in `data/`, not from these.

### Reproducing figures and tables

```bash
# 1. install dependencies
pip install -r requirements.txt

# 2. run the figure scripts from the repo root
python code/figures/generate_fig4_1.py   # Fig 2 in the paper (category structure)
python code/figures/generate_fig4_2.py   # Fig 3 (Jaccard matrices)
python code/figures/generate_fig5_1.py   # Fig 4 (temporal trajectory)
python code/figures/generate_fig5_2.py   # Fig 4 stage-category panel
python code/figures/generate_fig5_3.py   # Fig 5 (national coupling)
python code/figures/generate_fig6_1.py   # Fig 6 (spatial maps)
python code/figures/generate_fig6_2.py   # Fig 6 (regional × category heatmap)
python code/figures/generate_fig6_3.py   # Fig 7 (three-stage province scatter)
python code/figures/generate_fig6_4_sankey.py   # Fig 8 (province quadrant Sankey)
python code/figures/generate_fig_flowchart.py   # Fig 1 (processing flowchart)
```

Each script reads from `data/` and writes its figure into a sibling `figures/` directory (creating it on first run).

### Rebuilding the audit workbook

```bash
python code/audit/build_data_audit.py
python code/audit/audit_joint_issuance.py
```

These regenerate `outputs/audit/data_audit_master_v5.3.xlsx` and the joint-issuance classification sheets. Run `python code/compute_appendix_g.py` to reproduce the Appendix G coupling-statistics tables (sheets G1-G6).

## Methodology

The full description of data retrieval, keyword set, clause-level segmentation, semantic classification, structural break-point detection, entropy-weight composite index, the eight-class co-issuing-department scheme, and the detailed coupling-test statistics is in `docs/appendix.docx` (Appendices A–G of the paper). Appendix G consolidates the stage-wise and marginal-scale correlation tests and the provincial quadrant-transition matrices; the underlying CSVs are in `outputs/tables/appG_T1..T6_*.csv` and reproduce directly from `data/coupling/`.

Key methodological choices in brief:

| Step | Approach |
|---|---|
| Keyword retrieval | Recall-oriented 3-stage construction, 8 categories |
| Clause segmentation | Hierarchical anchoring on Chinese policy structure (章/节/条/编号) |
| Category classification | LLM-assisted initial pass + wide-coverage re-judgement + human-assisted review (verbatim prompt in `docs/llm_classification_prompt.md`) |
| Stage division | Dynp diagnostic + maximum YoY jumps + 5-year plan milestones, verified by ANOVA |
| S&T composite index | 4 indicators × 27 years × 31 provinces, entropy weights |
| Coupling typology | Median-threshold 4-quadrant typology over (P_t, S_t) |

## Data provenance and disclaimers

- Source policy texts are from the Pkulaw database (https://pkulaw.com), a commercial legal-information service. The dataset here contains the structured metadata (title, issuing authority, year, level, category labels) and clause-level extracts produced by our processing pipeline — not the original full-text PDFs, which remain subject to the source database's terms.
- Geo files (`china_provinces.geojson`, `china_cities.geojson`) are derived from publicly available administrative boundary data and are included for figure-rendering convenience only.
- Provincial S&T indicators are extracted from the *China Statistics Yearbook on Science and Technology* (multiple editions, National Bureau of Statistics of China and Ministry of Science and Technology). The yearbook tables underlying each indicator are listed in `docs/appendix.docx` (Table E1).
- All processing steps are described in the paper and `docs/appendix.docx`. The 33-sheet audit workbook in `outputs/audit/` lets reviewers trace every number in the paper back to the underlying data.
